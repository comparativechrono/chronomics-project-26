1. Count the units in every haplotype

A FASTA file spreads each sequence over several lines, which makes it awkward to treat as a table. seqtk seq -l0 writes each sequence on one line, and paste - - joins every two lines into one, with a tab between them: name, then sequence. Look at the first two – cut short, so they fit:

cd ~/project
seqtk seq -l0 results/haplotypes.fa | head -4 | cut -c 1-70
seqtk seq -l0 results/haplotypes.fa | paste - - | head -2 | cut -c 1-90

Now count CTGTCC, the first letters of every unit, in the sequence of each line. In awk, gsub(/CTGTCC/, "&", $2) replaces each CTGTCC in the second column with itself (so nothing changes) and says how many it replaced; substr($1, 2) is the name without its >. Save the result as a table, repeat_counts.tsv (.tsv: tab-separated values):

seqtk seq -l0 results/haplotypes.fa | paste - - | awk -F'\t' '{n = gsub(/CTGTCC/, "&", $2); print substr($1, 2) "\t" n}' > results/repeat_counts.tsv
head -4 results/repeat_counts.tsv
cut -f 2 results/repeat_counts.tsv | sort | uniq -c
Check

327 haplotypes with 4 units and 135 with 5 – the same as you counted from the genotypes in stage 3. Nobody has 3, 6 or any other number.

2. Count them another way

A result you got one way may be wrong in a way you cannot see. Get it a second way, and compare. Each haplotype is 600 letters long with five units, and each unit is 54 letters, so the letters outside the units are 600 − 5 × 54 = 330. From the length of a sequence, then, the number of units is (length − 330) / 54. Keep the lengths in a table:

seqtk comp results/haplotypes.fa | cut -f 1,2 > results/haplotype_lengths.tsv
head -3 results/haplotype_lengths.tsv

You will compare the two in R.

Run this cell, then change the numbers and run it again:

Everything after # is a comment, for people, not for R. length, mean and sum are functions: a name, then what it works on in brackets. To read the manual of a function, run ?mean.

Read the counts

A table in R is a data frame: columns with names, one row per thing. read.delim reads a tab-separated file into one. The file has no header line, so give the columns their names:

counts <- read.delim("~/project/results/repeat_counts.tsv", header = FALSE,
                     col.names = c("haplotype", "repeats"))
head(counts)
nrow(counts)
table(counts$repeats)
prop.table(table(counts$repeats))

counts$repeats is the column repeats of the data frame counts. table counts how many times each value occurs; prop.table turns the counts into fractions.

Check

462 rows; 327 fours and 135 fives; the five-repeat allele makes up 0.292 of the haplotypes – its allele frequency in these 231 people.

4. From haplotypes to people

A person has two haplotypes, and a genotype – 4/4, 4/5 or 5/5. The names say whose haplotype is whose: remove _hap1 or _hap2 from the end and you have the person. sub replaces a pattern – a regular expression again: [12] is "1 or 2", and $ "at the end".

counts$person <- sub("_hap[12]$", "", counts$haplotype)
head(counts)
length(unique(counts$person))

tapply applies a function to a column, group by group – here to the two counts of each person, which it sorts and pastes together:

genotype <- tapply(counts$repeats, counts$person, function(x) paste(sort(x), collapse = "/"))
head(genotype)
table(genotype)
Check

231 people: 113 are 4/4, 101 are 4/5 and 17 are 5/5.

Think

Archer et al. (2003) and Viola et al. (2007) compared 4/4 with 5/5 people. If you wanted 20 people of each genotype, and recruited people like these 231, how many would you have to genotype? What does that mean for studies of 5/5 people?

Your turn: do the two counts agree?

Read results/haplotype_lengths.tsv into a data frame with the columns haplotype and length, join it to counts with merge(counts, len) (if you called it len) (it matches the rows by the column they share, haplotype), and add a column with the number of units worked out from the length. Make a table of one count against the other: table(a, b) with two columns counts every pair of values. Do they agree for all 462? If not, which ones differ, and why?

Show a hint

both$from_length <- (both$length - 330) / 54. To see the rows that differ: both[both$repeats != both$from_length, ] – the rows for which the test is TRUE, and all the columns (nothing after the comma).

Show the answer 
len <- read.delim("~/project/results/haplotype_lengths.tsv", header = FALSE,
                  col.names = c("haplotype", "length"))
both <- merge(counts, len)
both$from_length <- (both$length - 330) / 54
table(motif = both$repeats, length = round(both$from_length, 2))
both[both$repeats != both$from_length, ]

They agree for 459 haplotypes. The three of 599 letters give 4.98 units from their length – their one-letter deletion outside the repeat (stage 3). The motif count is right for them; the length method assumed that nothing but the repeat changes the length. Each method has an assumption; checking one against the other shows where an assumption fails.
