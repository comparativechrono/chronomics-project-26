The 1000 Genomes Project sequenced 3,202 people with short reads – ten times as many as the pangenome, from 26 populations. Short reads cannot read the repeat, but they can read your tag. Check that the tag says the same as the long reads for the people in both projects, use it to map the repeat across 26 populations, and see what the short reads made of the repeat itself.

You will learn

1. The tag in the 1000 Genomes Project

1kgp_per3_gene.vcf.gz holds the phased variants of the 3,202 people of the high-coverage 1000 Genomes Project across PER3, from chr1:7,780,000 to 7,850,000. Its IDs are written chromosome:position:REF:ALT. Find your tag, and save everyone's genotype at it:

cd ~/project
bcftools query -l /data/examples/per3/1000g/1kgp_per3_gene.vcf.gz | wc -l
bcftools view -H /data/examples/per3/1000g/1kgp_per3_gene.vcf.gz | wc -l
bcftools query -r chr1:7829744 -f '%POS\t%ID\t%REF\t%ALT\n' /data/examples/per3/1000g/1kgp_per3_gene.vcf.gz
bcftools query -r chr1:7829744 -f '[%SAMPLE\t%GT\n]' /data/examples/per3/1000g/1kgp_per3_gene.vcf.gz > results/1kgp_rs228701.tsv
head -3 results/1kgp_rs228701.tsv
Check

3,202 people and 1,775 variants. rs228701 is 1:7829744:C:G: C/G, as in the pangenome. HG00096 is 1|1.

2. Does the tag agree with the long reads?

From the genotype, predict how many five-repeat alleles each person has: the G allele goes with four units (stage 7), so a person with 0|0 (C, C) should be 5/5 and have two, and so on. strsplit cuts each genotype at the bar.

kg <- read.delim("~/project/results/1kgp_rs228701.tsv", header = FALSE, col.names = c("sample", "gt"))
kg$G <- sapply(strsplit(kg$gt, "|", fixed = TRUE), function(a) sum(as.integer(a)))   # copies of G
kg$n5 <- 2 - kg$G                                       # predicted copies of the five-repeat allele
table(kg$n5)

Many of the HPRC's people were chosen from the 1000 Genomes Project, so they are in both: for them, the long reads are a truth set to check the prediction against. Count each person's five-repeat alleles in your allele table with aggregate (it applies a function to a column, group by group), and join:

alleles <- read.delim("~/project/results/vntr_alleles.tsv")
hprc <- aggregate(repeats ~ sample, alleles, function(r) sum(r == 5))
names(hprc)[2] <- "hprc_n5"
both <- merge(hprc, kg, by = "sample")
nrow(both)
table(long_reads = both$hprc_n5, tag_in_short_reads = both$n5)
mean(both$hprc_n5 == both$n5)
Check

222 people are in both. The tag predicts the long-read genotype of 221 of them: a concordance of 99.5%.

3. The repeat in 26 populations

Now use the tag where there are no long reads. Take the 2,504 unrelated people of the original project (the others are their parents and children, who would be counted twice), and work out the frequency of the five-repeat allele in each population: the number of five-repeat alleles divided by twice the number of people.

info <- read.delim("/data/examples/per3/1000g/1kgp_samples.tsv")
kg <- merge(kg, info, by = "sample")
un <- kg[kg$unrelated_2504 == "yes", ]
nrow(un)
f <- aggregate(n5 ~ population + superpopulation + population_name, un, function(x) sum(x) / (2 * length(x)))
names(f)[4] <- "freq5"
f$n <- as.vector(table(un$population)[f$population])
f <- f[order(f$superpopulation, f$freq5), ]
f
aggregate(n5 ~ superpopulation, un, function(x) round(sum(x) / (2 * length(x)), 3))
Check

2,504 people. The five-repeat allele: AFR 0.374, AMR 0.256, EAS 0.148, EUR 0.335, SAS 0.349 – from 0.081 in the Chinese Dai (CDX) to 0.403 in the Gambians (GWD).

4. What did the short reads see of the repeat?

The four-repeat allele is a 54-letter deletion against the GRCh38 reference, on 70% of chromosomes. Is it in the 1000 Genomes VCF? Look for variants near the repeat whose REF is long:

bcftools query -r chr1:7829001-7831000 -f '%POS\t%REF\t%ALT\n' /data/examples/per3/1000g/1kgp_per3_gene.vcf.gz | awk 'length($2) > 10'
bcftools query -r chr1:7830003 -i 'POS==7830003' -f '[%GT\n]' /data/examples/per3/1000g/1kgp_per3_gene.vcf.gz | tr '|' '\n' | sort | uniq -c

(-i 'POS==7830003' keeps only the variant that starts there: -r alone would also give the other deletion, which overlaps the position.)

Check

There are two long deletions, of 53 and 54 letters, inside the repeat. The 54-letter one is carried by 13 of 6,404 chromosomes (0.2%) – while the tag says about 70% of chromosomes have four units.

What does a read that spans the deletion look like?
