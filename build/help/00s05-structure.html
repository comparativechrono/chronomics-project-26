Stage 5 · What makes the alleles different

Week 5about 6 hours

Four units or five – but is every four-repeat allele the same? Studies of the repeat have nearly always treated it as two alleles, because that is all a PCR gel can show. With the whole sequence you can do better: cut every allele into its units, find which of the reference's units each one is, and translate them. The repeat turns out to have more than two kinds of allele.

You will learn
  • to write your own functions in R
  • to work with text in R: substr, gregexpr, strsplit, paste
  • to apply a function to every item of a list with sapply
  • the genetic code as a lookup table, and the difference between a synonymous and a missense change

1. A function that reads FASTA files

R has no built-in reader for FASTA files, so write one. A function is a recipe with a name: function(path) { … } takes a value, path, does the steps between the braces, and gives back the value of the last line. Read this one line by line before you run it:

read_fasta <- function(path) {
  lines <- readLines(path)                         # every line of the file
  starts <- grep("^>", lines)                      # the numbers of the lines that start with >
  ends <- c(starts[-1] - 1, length(lines))         # each sequence ends just before the next name
  seqs <- mapply(function(s, e) paste(lines[(s + 1):e], collapse = ""), starts, ends)
  names(seqs) <- sub("^>", "", lines[starts])       # name each sequence, without the >
  toupper(seqs)                                    # in capital letters
}
ref <- read_fasta("~/project/results/ref_region.fa")
nchar(ref)
haps <- read_fasta("~/project/results/haplotypes.fa")
length(haps)
head(nchar(haps))

mapply runs a small function on each pair of start and end, and paste(…, collapse = "") glues the lines of a sequence together. The result is a named vector: 462 sequences, each with the name of its haplotype (haps["HG00099_hap1"]).

2. Cut a sequence into its units

gregexpr finds every match of a pattern in a text and gives their positions; substr(s, p, p + 53) takes the 54 letters from position p. Together, they cut a sequence into its units:

units_of <- function(s) {
  starts <- gregexpr("CTGTCC", s)[[1]]
  sapply(starts, function(p) substr(s, p, p + 53))
}
ref_units <- units_of(ref)
names(ref_units) <- paste0("R", 1:5)
ref_units
identical(unname(ref_units), readLines("~/project/results/units_GRCh38.txt"))

The last line checks the function against the units you cut out with grep in stage 2. TRUE: the two methods agree.

3. Name every unit

Now the key idea. For each unit of each haplotype, ask: is it identical to one of the five units of GRCh38? If so, call it by that name (R1–R5). If not, find the reference unit it differs from least, and write down the differences: R4*8C means "like R4, but with a C at letter 8".

name_unit <- function(u) {
  same <- which(ref_units == u)
  if (length(same) == 1) return(names(ref_units)[same])
  letters_u <- strsplit(u, "")[[1]]                                   # the unit as single letters
  d <- sapply(ref_units, function(r) sum(strsplit(r, "")[[1]] != letters_u))   # differences from each
  best <- which.min(d)
  diffs <- which(strsplit(ref_units[best], "")[[1]] != letters_u)
  paste0(names(ref_units)[best], "*", paste0(diffs, letters_u[diffs], collapse = ","))
}
name_unit(ref_units[4])
name_unit(units_of(haps["HG00099_hap2"])[3])

5. What do they make?

Teach R the genetic code. The 64 codons, in the order of the table in stage 2 (first letter T, C, A, G; then the second; then the third), and their amino acids:

bases <- c("T", "C", "A", "G")
codons <- paste0(rep(bases, each = 16), rep(rep(bases, each = 4), 4), rep(bases, 16))
aa <- strsplit("FFLLSSSSYY**CC*WLLLLPPPPHHQQRRRRIIIMTTTTNNKKSSRRVVVVAAAADDEEGGGG", "")[[1]]
code <- setNames(aa, codons)

translate <- function(dna) {
  n <- nchar(dna) %/% 3                                   # the number of whole codons
  cods <- substring(dna, seq(1, by = 3, length.out = n), seq(3, by = 3, length.out = n))
  paste(code[cods], collapse = "")
}
sapply(ref_units, translate)

Your turn: synonymous or missense?

Compare the proteins of 5A and 5B, and of 4A and 4B. Do the A and B alleles make different proteins? For each difference in the DNA (R3*9G, R4*8C), work out which codon it falls in and what it does to it. Which change is synonymous (same amino acid) and which is missense (a different one)? What does the missense change add to the protein, given what you found about kinases in stage 2?

Show a hint

Letter 9 of a unit is the third letter of codon 3; letter 8 is the second letter of codon 3. Compare translate(ref_units["R4"]) with translate(units_of(haps[alleles$haplotype[alleles$type == "4B"][1]])[3]).

Show the answer

R3*9G changes codon 3 of R3 from ACA to ACG: both threonine, so 5A and 5B make the same protein. R4*8C changes codon 3 of R4 from ATG to ACG: methionine to threonine – a missense change that gives the 4B protein (LSTGLPP… in its third unit) one more threonine, a possible phosphorylation site, than the 4A protein. So the repeat makes three proteins, not two: five units, four units, and four units with an extra threonine.

Your finding

Most studies of the repeat have treated 4A and 4B as one allele, "4". If the A and B alleles differ in what they do – or in what else they carry with them – a study that lumps them together could miss an effect, or find one that belongs to a sub-type. Keep the types in mind: they come back in stage 9.
