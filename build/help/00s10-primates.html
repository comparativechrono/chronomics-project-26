2. Find the repeat in the protein

Read the DNA, and bring back your genetic code from stage 5. This version of read_fasta keeps only the first word of each name:

read_fasta <- function(path) {
  lines <- readLines(path)
  starts <- grep("^>", lines)
  ends <- c(starts[-1] - 1, length(lines))
  seqs <- mapply(function(s, e) paste(lines[(s + 1):e], collapse = ""), starts, ends)
  names(seqs) <- sub("^>(\\S+).*", "\\1", lines[starts])
  toupper(seqs)
}
bases <- c("T", "C", "A", "G")
codons <- paste0(rep(bases, each = 16), rep(rep(bases, each = 4), 4), rep(bases, 16))
code <- setNames(strsplit("FFLLSSSSYY**CC*WLLLLPPPPHHQQRRRRIIIMTTTTNNKKSSRRVVVVAAAADDEEGGGG", "")[[1]], codons)
translate <- function(dna) {
  n <- nchar(dna) %/% 3
  paste(code[substring(dna, seq(1, by = 3, length.out = n), seq(3, by = 3, length.out = n))], collapse = "")
}

The stretches on either side of the repeat are what you can search for in every species: just before the first unit, …SPATTGA (followed by the L that starts the first unit), and at the end of the last unit, …GSAA followed by S. Other species may have a slightly different letter here and there, so the pattern allows a choice at some places: [SN] means "S or N", and [A-Z]{2} "any two letters". This function finds the region between the two anchors in a protein:

repeat_region <- function(p) {
  start <- regexpr("[SN]P[AT][AT]T[A-Z]{2}L", p)       # the stretch just before the repeat, and its first L
  if (start < 0) return(NA)
  rest <- substr(p, start + 7, nchar(p))                # from that L onwards
  end <- regexpr("GS[AS]AS", rest)                      # the end of the last unit
  if (end < 0) return(NA)
  substr(rest, 1, end + 3)
}
repeat_region(frames[1])
nchar(repeat_region(frames[1])) / 18

In which frame is the repeat? You do not need to know: try all three, and keep the one where the region is found.

count_units <- function(s) {
  frames <- sapply(0:2, function(f) translate(substr(s, f + 1, nchar(s))))
  regions <- sapply(frames, repeat_region, USE.NAMES = FALSE)
  best <- which(!is.na(regions))[1]                     # the first frame in which the repeat is found
  if (is.na(best)) return(c(frame = NA, aa = NA, units = NA, region = NA))
  c(frame = best - 1, aa = nchar(regions[best]), units = round(nchar(regions[best]) / 18, 2), region = regions[best])
}
res <- t(sapply(dna, count_units))
res <- data.frame(sequence = rownames(res), res, row.names = NULL)
res$species <- gsub("_", " ", sub("\\|.*", "", res$sequence))
res[, c("species", "sequence", "aa", "units")]

4. An alignment and a tree

A multiple alignment lines up the proteins of all species, letter by letter, with gaps (-) where a species lacks letters others have. kalign makes one; the Files tab shows it in colour. Then FastTree builds a tree from it.

kalign -i /data/examples/per3/primates/PER3_proteins.fa -o results/PER3_proteins.afa
FastTree results/PER3_proteins.afa > results/PER3_proteins.nwk
head -c 300 results/PER3_proteins.nwk

Show the answer

Where the simians have their units, the tarsier, the lemurs and the dog have a single stretch that looks like one unit – the tarsier's …ELSMVLLHKESPSGTGSAAS…, for instance, next to the human last unit LSTGSPPSESPSRTGSAA – but the letters before it differ (CPTASEL rather than SPATTGAL), so the function's first anchor is not found. So NA here means one copy: the repeat – more than one copy of the unit – is found only in the simians, the monkeys and apes.
