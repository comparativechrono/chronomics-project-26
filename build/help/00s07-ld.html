The big studies of sleep never measured the repeat – but they measured millions of SNPs. If one SNP always sits on the same chromosomes as the five-repeat allele, then every study that measured that SNP has measured the repeat too, without knowing it. Find out whether such a SNP exists, using the 462 phased haplotypes of the pangenome.

Linkage disequilibrium

Every new mutation happens on one chromosome, next to the variants that chromosome already carries. Over the generations, recombination shuffles a chromosome's variants – but slowly: variants close together are rarely separated, and stay together on the same haplotypes for thousands of generations. Variants that occur together more often than chance are in linkage disequilibrium. The usual measure is r²: the square of the correlation between two variants across haplotypes, from 0 (independent) to 1 (one predicts the other perfectly). A tag SNP is one with a high r² with the variant you care about. A study of N people that measures a tag with r² has about the power of a study of r² × N people measuring the variant itself.

1. The variants around PER3, and their names

hprc_per3_500kb.vcf.gz has the variants of the same 231 people across 500,000 letters, from chr1:7,580,000 to 8,080,000 – PER3 and its neighbours. Each record is a single variant: the pangenome's bubbles were broken into SNVs, insertions and deletions. They have no names yet. dbSNP is the database that gives every known variant an rsID; dbsnp157_per3_500kb.vcf.gz holds its variants for the same stretch. bcftools annotate copies the ID of each dbSNP variant to the variant with the same position and alleles:

cd ~/project
bcftools view -H /data/examples/per3/hprc/hprc_per3_500kb.vcf.gz | wc -l
bcftools annotate -a /data/examples/per3/reference/dbsnp157_per3_500kb.vcf.gz -c ID -Oz -o results/hprc_500kb_rsid.vcf.gz /data/examples/per3/hprc/hprc_per3_500kb.vcf.gz
bcftools view -H results/hprc_500kb_rsid.vcf.gz | cut -f 1-5 | head
bcftools query -f '%ID\n' results/hprc_500kb_rsid.vcf.gz | grep -c "^rs"

-a names the file to take the IDs from, -c ID the column to copy, and -Oz -o writes a compressed VCF.

Check

7,441 variants, of which 6,890 now have an rsID. Those without are new, or written differently in the two files.

2. A table of haplotypes

Keep the simplest variants – SNVs with two alleles – and write their genotypes as a table: -m2 -M2 keeps variants with exactly two alleles, -v snps only SNVs. In the query, what is between [ ] is repeated for every person; sed 's/|/\t/g' turns each 0|1 into two columns, one per haplotype.

bcftools view -m2 -M2 -v snps results/hprc_500kb_rsid.vcf.gz | bcftools query -f '%POS\t%ID\t%REF\t%ALT[\t%GT]\n' | sed 's/|/\t/g' > results/snv_haplotypes.tsv
wc -l results/snv_haplotypes.tsv
cut -f 1-12 results/snv_haplotypes.tsv | head -3
bcftools query -l results/hprc_500kb_rsid.vcf.gz > results/samples_in_vcf_order.txt
Check

6,140 SNVs, each a row of 4 + 462 columns: position, rsID, the two alleles, then 0 or 1 for each haplotype. A few genotypes are . – unknown, where one of a person's assemblies has a gap.

3. r² with the repeat

Read the table and name its columns: the haplotypes are in the order of the VCF's samples, two each.

snv <- read.delim("~/project/results/snv_haplotypes.tsv", header = FALSE, na.strings = ".")
dim(snv)
samples <- readLines("~/project/results/samples_in_vcf_order.txt")
hap_names <- paste0(rep(samples, each = 2), "_hap", 1:2)
head(hap_names)
colnames(snv) <- c("pos", "rsid", "ref", "alt", hap_names)
G <- as.matrix(snv[, hap_names])     # a matrix: one row per SNV, one column per haplotype
dim(G)
G[1:3, 1:6]

Now the repeat, as a row of the same kind: 1 for a five-repeat haplotype, 0 for a four-repeat one, in the same order as the columns of G. match finds where each name of hap_names is in your allele table, so the order is right whatever the order of the table.

alleles <- read.delim("~/project/results/vntr_alleles.tsv")
vntr <- ifelse(alleles$repeats[match(hap_names, alleles$haplotype)] == 5, 1, 0)
table(vntr)
cor(G[1, ], vntr, use = "complete.obs")^2

The last line is r² between the first SNV and the repeat (use = "complete.obs" skips the unknown genotypes). apply(G, 1, f) does the same for every row of G:

r2 <- apply(G, 1, function(x) suppressWarnings(cor(x, vntr, use = "complete.obs"))^2)
snv$r2 <- r2
top <- snv[order(-snv$r2), c("pos", "rsid", "ref", "alt", "r2")]
head(top, 10)

(suppressWarnings hides the warnings of SNVs that every haplotype shares: their correlation cannot be computed, and is NA.)

Check

Two SNVs have r² = 0.990 with the repeat: rs228701 (7,829,744, C/G) and rs1773135 (7,830,204, A/G), 144 letters before the first unit and 47 after the last. Next come rs228665 (0.878) and rs12023156 (0.748).

5. Does the tag work everywhere?

LD differs between populations: African populations are older and have had more time for recombination to break haplotypes up. A tag that works in Europeans may fail in Africans. Test the two best SNVs in each continental group:

samp <- read.delim("/data/examples/per3/hprc/hprc_samples.tsv")
sup <- samp$superpopulation[match(sub("_hap[12]$", "", hap_names), samp$sample)]
row_of <- function(id) which(snv$rsid == id)[1]      # the row of a SNV, from its rsID
best <- c("rs228701", "rs1773135")
sapply(split(seq_along(vntr), sup), function(i)
  sapply(best, function(id) cor(G[row_of(id), i], vntr[i], use = "complete.obs")^2))

split makes a list of the column numbers of each group, and sapply works out r² within each.

Check

r² = 1 in AMR, EAS, EUR and SAS, and 0.970 in AFR.

The G allele of rs228701 (coded 1) is on 326 of the 327 four-repeat haplotypes, and the C allele (0) on all 135 five-repeat ones. Which haplotype is the exception? Look up its structure in your allele table. What could explain it?

HG02257_hap2 – the rare R1-R2-R4*8C,14C-R5 allele of stage 5, which lacks R3 rather than R2. It has four units, but the SNVs around it are those of five-repeat haplotypes. The likeliest story: a five-repeat chromosome lost a unit a second time, separately from the event that made the common four-repeat alleles. A tag cannot follow a change that happened again on another haplotype – and that is the 1% of r² that is missing.
